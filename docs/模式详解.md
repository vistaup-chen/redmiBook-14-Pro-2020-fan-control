# 模式详解

> 每个模式 = 1 个电源方案（Windows 性能设置） + 1 份 NBFC 风扇曲线（EC 控制）。
> 两者由 `mode-switch.ps1` 一键同时切换，且 AC（插电）/DC（电池）参数完全一致——与插不插电无关。

## 风扇曲线的表示方法

NBFC 曲线是「温度档位表」：温度升到某档的 `UpThreshold` 就切到该档转速，跌回 `DownThreshold`
以下才降档（滞回防抖）。转速百分比线性映射到 EC 占空比（本机 0→200，100%→88，值越小越快）。

- 本机实测关键点：占空比 ≥200（0%）≈ 停转；164（≈32%）≈ 最低可转档；119（100%）= 全速。
- NBFC 的 `CriticalTemperature` 是硬保险：温度超过它时**无视曲线直接 100%**，降到该值-15℃ 以下才恢复。

---

## 1. 静音模式（日常默认）`Silent`

**用途**：轻办公、网页、视频、远程会议。目标：风扇绝大多数时间 0 转。

| 项 | 值 |
|---|---|
| 电源方案 | Z-fan Silent：最大处理器状态 **60%**（效率核 75%）、EPP 60、加速模式禁用 |
| 风扇曲线（v2） | ≤58℃ **0%** → 58℃ 35%（最低档） → 64℃ 55% → 70℃ 75% → 74℃ 100% |
| 滞回回差 | 每档 6-7℃（58 降回 51 才停转），消除边界转/停抖动 |
| 硬保险 | CriticalTemperature 76℃ → 强制 100% |
| 硬件效果 | CPU 封顶 ~1.4GHz，单核突发仍可到 ~2.3GHz 非睿频上限；网页/视频/办公无感知差异 |

**实测**（2026-10-29，4 线程 50% 负载 + 日常后台）：
- v1 曲线（55℃ 起转）：温度全程 53-58℃，风扇 t+20s 升到 35%（最低档）后保持。
- v2 曲线（58℃ 起转）：同一负载下风扇 0% 的窗口更宽，边界抖动消除（55℃ 时保持 0 转）。
- 对比：EC 自动模式在同温度下风扇 ≈59% 档持续运转——静音模式的日常噪音改善是决定性的。

**调参建议**：
- 想更静：把 58/51 那一档的 UpThreshold 提到 60（机器会更热一点点）。
- 想更稳：把 35% 提到 40%（起转更果断，噪音几乎无差别）。
- 若你的环境温度高（夏天无空调），建议改回 55。

## 2. 勿扰全静（`DoNotDisturb`）

**用途**：睡前刷网页、开在线会议、需要绝对安静的 1-2 小时。接受机身更热。

| 项 | 值 |
|---|---|
| 电源方案 | Z-fan DoNotDisturb：最大处理器状态 **50%**（效率核 60%）、EPP 80、加速禁用 |
| 风扇曲线（v2） | ≤60℃ **0%** → 60℃ 40% → 68℃ 70% → 74℃ 100% |
| 硬保险 | CriticalTemperature 76℃ |

**预期**：轻载下全程无声；机身表面温度比静音模式更暖（约 +3-5℃）。**不建议**在此模式跑重负载。

## 3. 均衡模式（`Balanced`）

**用途**：编译、虚拟机、多开、偶尔的游戏。性能优先，噪音合理。

| 项 | 值 |
|---|---|
| 电源方案 | Z-fan Balanced：最大处理器状态 **100%**、EPP 40、加速模式启用 |
| 风扇曲线（v2） | ≤50℃ 0% → 50℃ 40% → 60℃ 60% → 70℃ 85% → 76℃ 100% |
| 硬保险 | CriticalTemperature 80℃ |

**预期**：轻载依旧安静；重负载时风扇随温度平滑上升，人感噪音显著低于原厂曲线（原厂在更低温度就用更高档位）。

## 4. 极限性能（`Performance`）

**用途**：短时最大性能——导出/渲染/极限编译。吵是设计内的代价。

| 项 | 值 |
|---|---|
| 电源方案 | Z-fan Performance：最大处理器状态 **100%**、EPP **0**（最激进能效策略）、加速模式**激进(Aggressive)** |
| 功耗墙 | MSR 0x610 的 **PL1 25W → 28W**（保持使能/clamp/时间窗/PL2≈51W 不动）；写入即生效，重启后失效，退出本模式自动还原 25W |
| 风扇曲线（v2） | ≤42℃ 40% → 44℃ 65% → 54℃ 85% → 63℃ **100%** |
| 硬保险 | CriticalTemperature 78℃ |

**预期**：多核持续功耗 25→28W（约 +12% 持续性能），单核睿频 4.9GHz 更快进入；风扇提前领跑压温度。
> 满载稳定性说明：遵守「不长时间满载干扰其他任务」的约束，28W 未做长时间满烧机测试（出厂 25W
> 已验证稳定，28W 是保守的小幅解锁；IT之家对该机型的评测显示其短时可跑 25W+）。若极端情况下
> 出现不稳定，双击「恢复默认」即可。

## 5. 智能自动（可选，默认关）

双击 `智能自动-开.bat` 创建并启用计划任务 `ZFanAutoMode`（SYSTEM 权限，每分钟一次）：

- 只在**静音 ↔ 均衡**之间切换：EC 温度 ≥62℃ 连续 2 次 → 自动升到均衡（风扇正常散热）；
  ≤54℃ 连续 5 次 → 自动回静音。切换后 3 分钟冷却期防抖。
- 你手动切到**极限/勿扰/恢复默认**时观察器自动让位，绝不插手。
- 决策依据是 EC 温度而非 CPU 占用——不受限频/后台任务干扰，直接对应风扇的散热压力。
- 日志在 `logs\auto-mode.log`，`状态查看.bat` 会显示开关状态和最近一次决策。

**默认关闭**——想全手动控制就不用开它。开启后想恢复纯手动：双击 `智能自动-关.bat`。

## 6. 恢复默认（`restore`）

1. 停止 NBFC 控制 → 服务自动把 EC 0x93 写回 0x04（自动模式）、占空比写回 0xFF，风扇交还固件原厂曲线。
2. 电源方案切回系统原有的「节能」方案（你改造前的状态）。
3. 若功耗墙被极限模式改过 → 写回原始值 `0x0042819800DD80C8`（备份在 `data\msr-610-original.txt`，脚本与 UI 共用同一份）。

## 7. 模式与插电无关的实现

Windows 电源方案的每个参数都有 AC/DC 两份设置。四个方案创建时**同时写入了两份相同的值**
（`powercfg /setacvalueindex` + `/setdcvalueindex`），并已用 `/qh` 逐一核对。
NBFC 曲线本身没有电源来源概念。极限模式的 MSR 写入同样不区分电源来源。
因此：插电/电池行为完全一致。
