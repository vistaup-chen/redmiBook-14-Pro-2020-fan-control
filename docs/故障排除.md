# 故障排除

## 症状：界面「点一下没反应」/ 卡顿（2026-10-30 起已修复）

旧版本每 5 秒在 UI 线程上同步运行 nbfc status、3 次 ec-probe read、powercfg、schtasks、
ServiceController 查询（每个 8 秒超时），任一子进程缓慢就会把整个窗口冻结几秒；工具页的
智能自动/DPTF 按钮更是直接在 UI 线程同步跑 30 秒命令。当前版本已全部移入后台状态引擎，
UI 线程不再运行任何子进程。

如果仍然感觉没反应，按顺序查：

1. 看底部日志面板的「状态： xxx」一行——正在执行的每一步（1/4、2/4…）都会显示；
   忙碌期间的点击会提示「上一操作还在进行中」而不是无声无息。
2. 看自测页：管理员权限、NBFC 服务、WinRing0 驱动三项必须 OK。
3. 未提权启动时顶部会出现黄色横幅（带「重新提权启动」按钮）；NBFC 服务未运行同样有横幅。

## 症状：风扇一直 0 转，但机身很烫 / 风扇一直转，停不下来

先双击 `状态查看.bat`，看三样东西：

1. **Temperature**：NBFC 读到的 CPU 温度。
2. **Current/Target fan speed**：当前/目标转速档位。
3. EC mode(147)：`0x14`=NBFC 手动控制中，`0x04`=EC 自动。

| 观察 | 结论 | 处理 |
|---|---|---|
| mode=0x14，Target=0，但温度 70℃+ | 曲线阈值被改得过松 | 双击对应模式 .bat 重载配置；或按 docs\模式详解.md 收紧阈值 |
| mode=0x04 | NBFC 没在控制（被停了） | `状态查看` 无异常的话，双击想要的模式 .bat；仍不行看下一条 |
| mode=0x14 但 Target 恒 0 且温度读数异常（0 或 -1） | NBFC 温度传感器读挂了 | 管理员运行 `Restart-Service NbfcService`；重启机器亦可 |
| 风扇狂转且 mode=0x04，温度不高 | EC 固件自己的判断（传感器差异），或进了 NBFC 的 Critical 状态 | 看 NbfcServiceLog（下文路径） |

**万能恢复**：双击 `紧急恢复风扇.bat` —— 强制写 EC 0x93=0x04 交还固件自动控制，风扇行为立刻回到出厂逻辑。

## 症状：模式切换后没有变化

- 看输出里「Selected config name」是否变成目标模式、电源方案 GUID 是否为 Z-fan 对应项。
- NBFC 切配置后 1-2 秒内生效；电源方案即时生效。
- 若 360/Defender 拦截了 NbfcService（本机实测未发生），服务被停 → 以管理员运行：
  `net start NbfcService`，再双击模式 .bat。

## 症状：NbfcService 反复崩溃/重启

查日志：`C:\ProgramData\NbfcService\NbfcServiceLog.txt`。
已知风险：NBFC 1.6.3 的温度插件在部分新 CPU 上不兼容导致崩溃循环（nbfc-revive issue #27）。
本机 i7-10510U 实测**正常**（温度 50-62℃ 读数连续正确）。若 BIOS 大版本更新后出现此症状，
用 nbfc-revive issue #27 中 basso314 提供的新版 OpenHardwareMonitorLib.dll 替换
`C:\Program Files (x86)\NoteBook FanControl\Plugins\` 里的同名文件。

## 杀软相关（本机为 360 安全卫士 + Defender）

- NBFC 驱动（WinRing0_1_2_0）与 EC 写入：**实测 360 未拦截**。
- 360 曾**静默隔离**我们自编译的无签名 MSR 工具（msr.exe）。最终方案已改用 NBFC 自带库的
  反射调用，不落地新二进制，不会再触发。若你手动重建 `scripts\lib\msr.cs` 后发现 exe 消失，
  就是杀软干的——不要对抗杀软，继续用 msr-lib.ps1 反射方案。
- 不要给 NBFC 目录添加排除项（没必要，也避免安全面扩大）。

## 风扇为什么没有「转速 RPM」显示

本机 EC 的 RAM 里没有暴露 16 位转速计数器（已用多阶段转储对比法排除），NBFC 显示的是
占空比百分比映射，不是真实 RPM。

当前版本的通用做法：**估算转速 = NBFC 风扇% × 满载转速**（工具页「风扇转速估算」可改
MaxFanRpm，默认 7000，用 BIOS/其它工具读到真实满载转速后填入即可校准），界面明确标注
「估算」并同时给出风扇状态语义（停转/低速/中速/高速，占空比反向映射分档）。若以后想找
真实 RPM：可按 [ec-dump-experiments.md](ec-dump-experiments.md) 的转储对比法对 EC bank1+
（0xFF 为 bank 选择寄存器）做只读扫描，风险与收益都不大，故未默认启用。

## 温度看哪个才准

- NBFC status 的 Temperature：NBFC 控制用的温度源（取自其 CPU 温度插件）。
- EC 0xA8（168）：EC 自带的 CPU 温度，与 NBFC 读数差 0-4℃，趋势一致。
- 二者任一超过 75℃ 都会触发硬保险（视当前模式的 CriticalTemperature）。

## 恢复出厂（完整卸载流程）

1. `恢复默认.bat`
2. 控制面板 → 卸载 NoteBook FanControl
3. 删除本仓库目录（风扇控制项目文件夹）
4. （可选）删除 4 个 Z-fan 电源方案：
   `powercfg /delete 9a10e4a1-1111-4b7a-8c0d-000000000001`（…002/003/004 同理）
