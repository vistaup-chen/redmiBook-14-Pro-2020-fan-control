# RedmiBook 14 Pro 2020 风扇控制 / 性能模式

针对小米 RedmiBook 14 系列笔记本（TIMI TM1901 主板，i7-10510U + MX250，Windows 10/11）的
风扇控制与性能模式方案。通过 ACPI EC（嵌入式控制器）直接接管风扇曲线，解决原厂
「怠速即中速转、风扇吵」的问题；配合专属电源方案，提供从「全程 0 转」到「解锁 28W」的完整区间。

> **实测机型**：RedmiBook 14 增强版 2020（TM1901，BIOS RMRCM400P0100）。
> 同代 RedmiBook / 小米笔记本（ITE EC）理论上可参考，但寄存器映射需按 [docs/技术原理.md](docs/技术原理.md)
> 的方法重新验证后再使用。

## 核心能力

- **四个模式**（均与插电/电池无关，AC/DC 参数一致）：
  | 模式 | 风扇 | 性能 |
  |---|---|---|
  | 静音模式（日常默认） | ≤58℃ 全程 0 转，之后最低档轻柔介入 | 60% 状态、睿频关 |
  | 勿扰全静 | ≤60℃ 0 转 | 50% 状态 |
  | 均衡模式 | ≤50℃ 停转，随温度平滑上升 | 全性能 + 睿频 |
  | 极限性能 | 风扇先行领跑 | PL1 25W→**28W** + EPP 0 + 激进睿频 |
- **GUI「风扇管家」**：模式切换、实时监控、风扇曲线可视化编辑、手动风扇（含过热自动交还）、
  智能自动（温度驱动的静音↔均衡切换）、全局频率上限、DPTF 解锁、内置自测
- **安全兜底**：每套曲线有过热强推 100% 的 CriticalTemperature；手动模式温度超限自动交还；
  NBFC 服务崩溃自动重启；紧急脚本一键把风扇控制权交还 EC 固件

## 快速开始

0. 前置：已安装 [NBFC](https://github.com/hirschmann/nbfc)（本仓库脚本假定服务名 `NbfcService`、
   目录 `C:\Program Files (x86)\NoteBook FanControl`，安装时选本机对应配置或先用只读模式验证）。
1. 把 `nbfc-configs/` 里的 4 份 XML 复制到 NBFC 的 `Configs\` 目录；
2. 以管理员运行 `scripts/setup-plans.ps1` 创建 4 个电源方案（AC/DC 同值）；
3. 双击 `scripts/静音模式.bat` 体验风扇 0 转；或按 `ui/README.md` 启动图形界面。

> 首次务必以 `nbfc start -r`（只读）确认温度读数正常后再切正式控制。

## 技术原理（30 秒版）

- 本机 EC 的风扇占空比寄存器为 **0x94**（反向映射：值越小转速越快，≥0xC8≈停转），
  **0x93** 为控制权（0x1C 手动 / 0x04 自动，必须先写模式再写占空比），0x95 为回读校验，
  0xA8 为 CPU 温度。原厂自动曲线在怠速即写 ≈59% 档——这就是风扇吵的根源。
- 功耗墙通过 MSR 0x610 解锁（出厂 PL1=25W/PL2≈51W，未锁定），极限模式写 28W，退出自动还原。
- 详情与实测数据见 [docs/技术原理.md](docs/技术原理.md)。
